# Hex-to-RGB API

A simple JavaScript library and Express REST API for converting hexadecimal color values to RGB.

## Installation

```bash
npm install
```

## Run the API

```bash
npm start
```

API endpoint: `GET /api/hex-to-rgb/:hex`

Example: `http://localhost:3000/api/hex-to-rgb/FF0000`

## Run tests

```bash
npm test
```

Tests use Jest and Supertest, covering unit and integration tests.
